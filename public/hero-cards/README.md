# Folder Gambar Floating Cards (Hero Section)

Folder ini (`public/hero-cards/`) digunakan untuk foto/gambar pada 5 kartu melayang (*Polaroid cards*) di halaman utama (Hero Section).

---

### 📐 Rekomendasi Ukuran Gambar:
* **Rasio Aspek**: **`5 : 4`** atau **`4 : 3`** (Landscape Sedang)
* **Resolusi Ideal**: **`600 × 480 px`** (atau **`720 × 576 px`**)
* **Format**: `.jpg`, `.png`, atau `.webp`
* **Ukuran File**: Di bawah 200 KB per gambar agar loading website sangat cepat.

---

### 🏷️ Rekomendasi Nama File:
1. `card-1.jpg` (atau `.png`) ➔ **Kartu 1 (Kiri Atas)**
2. `card-2.jpg` (atau `.png`) ➔ **Kartu 2 (Kanan Atas)**
3. `card-3.jpg` (atau `.png`) ➔ **Kartu 3 (Kiri Bawah)**
4. `card-4.jpg` (atau `.png`) ➔ **Kartu 4 (Kanan Bawah)**
5. `card-5.jpg` (atau `.png`) ➔ **Kartu 5 (Tengah Atas)**

---
*Semua gambar yang ditaruh di sini dapat langsung diakses melalui path `/hero-cards/card-1.jpg`, dst.*
