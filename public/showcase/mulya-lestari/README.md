# Folder Gambar Showcase Mulya Lestari

Silakan letakkan screenshot atau foto aplikasi **Mulya Lestari** di folder ini (`public/showcase/mulya-lestari/`).

### Rekomendasi Nama File:
1. `hero.png` (atau `hero.jpg` / `hero.webp`) ➔ **Tampilan Utama Aplikasi / Dashboard / Halaman Login**
2. `gallery-1.png` (atau `gallery-1.jpg` / `gallery-1.webp`) ➔ **Screenshot Modul Kasir / Pencatatan Servis**
3. `gallery-2.png` (atau `gallery-2.jpg` / `gallery-2.webp`) ➔ **Screenshot Laporan / Stok / Multi-Cabang**

---
*Semua gambar yang ditaruh di sini akan otomatis dapat diakses melalui path `/showcase/mulya-lestari/nama-file.png`.*
