# Folder Gambar Showcase Astro Commerce D2C

Silakan letakkan screenshot atau foto aplikasi **Astro Commerce D2C** di folder ini (`public/showcase/astro-commerce/`).

### Rekomendasi Nama File:
1. `hero.png` (atau `hero.jpg` / `hero.webp`) ➔ **Tampilan Hero / Mockup Utama Toko Online**
2. `katalog-filter.png` (atau `katalog-filter.jpg` / `katalog-filter.webp`) ➔ **Screenshot Katalog & Instant Filter Produk**
3. `checkout-qris.png` (atau `checkout-qris.jpg` / `checkout-qris.webp`) ➔ **Screenshot Checkout, Hitung Ongkir & QRIS**

---
*Semua gambar yang ditaruh di sini akan otomatis dapat diakses melalui path `/showcase/astro-commerce/nama-file.png`.*
